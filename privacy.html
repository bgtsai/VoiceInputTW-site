存取哪些 Google 資料 What Google data is accessed

只使用 drive.appdata 權限，也就是你的 Google 雲端硬碟裡專門給這個程式用的隱藏資料夾。這個程式看不到、也不會讀取或修改你雲端硬碟裡的其他檔案。

Only the drive.appdata scope is used: a hidden folder in your Google Drive reserved for this program. The program cannot see, read or modify any other files in your Drive.

存了什麼 What is stored

設定值、熱詞替換清單、辨識引擎的 API 金鑰，以及備份的時間和電腦名稱。不包含錄音，也不包含你說過的內容。

Settings, the hot-word replacement list, API keys for speech recognition engines, and the backup time and computer name. No audio recordings and no dictated content are stored.

金鑰怎麼保護 How API keys are protected

備份裡的 API 金鑰靠你的 Google 帳號保護：只有登入這個帳號、而且經過你授權的這個程式讀得到。

API keys in the backup are protected by your Google account: only this program, signed in to your account and authorized by you, can read them.

資料給誰 Data sharing

資料只存在你自己的 Google 帳號裡。開發者收不到，也不會提供給任何第三方。這個程式沒有自己的伺服器。

Data stays in your own Google account only. The developer does not receive it, and it is never shared with any third party. This program has no server of its own.

怎麼刪除 How to delete your data

  • 在程式裡刪除備份。Delete backups from within the program.
  • 到 Google 雲端硬碟「設定 → 管理應用程式」，選「語音輸入法」，按「刪除隱藏的應用程式資料」。In Google Drive, go to Settings → Manage apps, choose this app, and select "Delete hidden app data".
  • 到 Google 帳號的第三方存取權頁面移除授權。Remove access on your Google Account's third-party access page.
