語音輸入法（VoiceInputTW）

Windows 上的語音輸入工具：按住快捷鍵說話，放開後把辨識出的繁體中文文字輸入到目前的視窗。這是個人自用的程式，不公開發行。

A voice input tool for Windows: hold a hotkey and speak; when released, the recognized Traditional Chinese text is typed into the current window. This is a personal-use program and is not publicly distributed.

「設定備份」功能會用你的 Google 帳號，把設定存到 Google 雲端硬碟裡只有這個程式看得到的隱藏資料夾。

The "Settings backup" feature uses your Google account to store settings in a hidden folder in your Google Drive that only this program can access.
